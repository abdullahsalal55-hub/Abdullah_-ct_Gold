# Abdullah ICT Gold

منصة تعليمية عربية مجانية لشرح منهج ICT وتطبيق مفاهيم السيولة وبنية السوق على الذهب XAUUSD والناسداك.

## الموقع

https://abdullahsalal55-hub.github.io/Abdullah_-ct_Gold/

## المحتوى

- منهج تعليمي عربي باتجاه RTL وتصميم أسود وذهبي.
- 225 وحدة/دفعة تعليمية مرقمة داخل مكتبة ICT.
- دروس في السيولة، بنية السوق، مناطق الاهتمام، التوقيت، وإدارة المخاطر.
- محتوى تعليمي فقط؛ لا توجد وعود بأرباح أو توصيات مضمونة.

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح. لا يحتاج الموقع إلى تثبيت حزم أو إعداد خادم.

## النشر

الموقع ثابت (HTML/CSS/JavaScript) ويُنشر عبر GitHub Actions من الفرع `main` باستخدام سير العمل الموجود في `.github/workflows/pages.yml`.

كل تحديث يُرفع إلى `main` يشغّل سير عمل GitHub Pages تلقائياً. ويمكن تشغيله يدوياً من تبويب **Actions**.

## تنبيه المخاطر

المحتوى لأغراض التعليم ودراسة الأسواق فقط، ولا يمثل نصيحة استثمارية أو ضماناً للربح. التداول ينطوي على مخاطر وقد يؤدي إلى خسارة رأس المال.
